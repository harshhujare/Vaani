3. Detailed Step-by-Step BreakdownStep 1: Voice Ingestion & Entity ExtractionConverts speech to text using regional speech engines.   The extraction LLM converts unstructured statements into raw attributes (occupation, experience_years, raw_skills, assets, education, interests, location, preference).   Step 2: Canonical NormalizationNatural language skill descriptions vary widely (e.g., "कपडे शिवणे", "सिलाई", "dress alteration").   Uses an alias table and semantic lookup to map inputs to verified Canonical Skill IDs in the database.   Unrecognized or hallucinated skills outside the database are excluded.   Step 3: Candidate Retrieval (Dual Funnel)To evaluate thousands of national qualifications efficiently:SQL Broad Filter: Queries active qualifications in matching sectors.   Vector Search (pgvector): Matches profile context against qualification descriptions via cosine similarity to catch adjacent roles.   Merge: Aggregates both pipelines into a candidate pool of 50–100 qualifications.   Step 4: Hard Eligibility Gate (Binary Evaluation)Before any scoring takes place, strict prerequisite checks eliminate invalid courses:   Education: beneficiary.education >= qualification.min_education   Experience: beneficiary.experience >= qualification.min_experience   Course Validity: qualification.is_active == True   Step 5: 100-Point Heuristic Scoring ModelEach eligible candidate qualification is scored from $0$ to $100$:   $$\text{Final Score} = \sum (\text{Component Score} \times \text{Weight})$$ComponentWeightCriteria & Measurement BasisSkill Compatibility30%Weighted overlap between user skills and required course standards.   Interest Alignment20%Semantic match between user goals and qualification outcomes.   Experience Relevance15%Alignment between past working years and subject area.   Education Match10%Direct baseline compliance with educational prerequisites.   Asset Compatibility10%Ownership of necessary functional tools (e.g., sewing machine, basic tools).   Location / Accessibility5%Distance scale ($100$ points for $<5\text{ km}$, scaled down to $30\text{ km}$).   Employment Preference5%Preference match: Self-employment vs. Wage employment.   Batch Availability5%Open seats in the nearest upcoming training cycle.   Step 6: Ranking & Diversity FilteringEligible qualifications are sorted in descending order by final score.   A diversity filter prevents redundant recommendations by assigning pathways into three distinct tiers[cite: 1]:Best Match: Closest fit to current skills and profile[cite: 1].Growth Path: Slightly higher NSQF level aligned with future interests[cite: 1].Alternative Option: Practical, viable lateral pathway[cite: 1].Step 7: Skill Gap ExtractionPerforms mathematical set subtraction against course competencies:$$\text{Skill Gaps} = \text{Required Competencies} \setminus \text{Possessed Competencies}$$Categorizes the output into Strengths (possessed) and Gaps (to be trained)[cite: 1].Step 8: Nearest Training Center MatchingComputes Haversine distance from the beneficiary coordinates to all authorized centers running the selected qualification[cite: 1].Selects the closest facility with active seat capacity[cite: 1].Step 9: Guardrailed Explanation GenerationThe LLM is supplied with the raw numbers, matched skills, gaps, and center details as strict context[cite: 1].Generates a 2-sentence rationale in the beneficiary's local language explaining why the course was selected[cite: 1].Guardrails prohibit hallucinating placement guarantees or unauthorized stipends[cite: 1].4.
